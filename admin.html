❓ Token akkamitti argadha?
  1. Tab haaraatti bani: github.com/settings/personal-access-tokens/new
  2. Token name: barii-admin · Expiration: 1 year
  3. Repository access → Only select repositories → repository kee filadhu
  4. Permissions → Repository permissions → Contents → Read and write
  5. Generate token tuqi → token (github_pat_…) Copy godhiitii asitti Paste godhi

🔒 Token kun jecha icciitii keetiin cufamee (encrypt) kuufama. Namni jecha icciitii fi PIN kee hin beekne itti fayyadamuu hin danda'u.
